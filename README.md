# 拾光小径 · 像素冒险

纯前端横版平台小游戏，所有画面均由 Canvas 几何图形自绘，无外部素材、字体、商标或运行依赖。

## 打开方式

直接用浏览器打开 `index.html` 即可游玩。也可在本目录运行：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000 。停止服务按 `Ctrl+C`。

如果系统没有 `python` 命令（例如当前开发环境），请使用 `python3 -m http.server 8000`，效果相同。

## 操作和规则

- 点击「开始冒险」。← / → 或 A / D 移动；空格 / W / ↑ 跳跃。按住跳得更高，轻点小跳。
- P / Esc 或「暂停」暂停和继续；「重新开始」重置整局。切换到其他窗口会自动暂停。
- 手机和平板可使用底部方向和跳跃按钮，建议横屏。
- 金币每枚 100 分，顶问号箱获得一枚金币。砖块可以顶动，问号箱只奖励一次。
- 从上方落在地面小怪身上可消灭小怪并获得 200 分，同时向上弹起。
- 侧面碰怪扣一条生命，有短暂无敌时间；掉入沟壑扣命并回到关卡起点，保留已获得的分数、金币和关卡状态。
- 初始 3 条生命；生命耗尽可以再来一次。抵达右侧旗杆通关，额外获得 1,000 分。

## 文件

- `index.html`：页面、HUD、菜单与响应式样式。
- `game.js`：固定时间步物理、关卡、输入、碰撞和 Canvas 绘制。
- `README.md`：运行说明。

无需安装 npm 包或执行构建。适合支持 Canvas 和 Pointer Events 的现代浏览器。
